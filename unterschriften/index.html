Klare Regeln.

Wen unterstützt meine Unterschrift?

Sie unterstützen Getu Abrahams Wahlvorschlag für die Oberbürgermeisterwahl 2027. Das verpflichtet Sie nicht, ihn später zu wählen. Für dieselbe Wahl dürfen Sie nur einen Wahlvorschlag unterstützen.

Wer darf unterschreiben?

Unterstützen dürfen die zum Zeitpunkt der Unterschrift in Leipzig für diese Wahl Wahlberechtigten. Das Amt prüft die Voraussetzungen. Ein Ausweisdokument ist mitzubringen.

Geht es auch online oder auf einer privaten Liste?

Nein. Private Unterschriftenlisten, eine Online-Unterzeichnung oder eine Einsendung per Post ersetzen die amtliche Unterstützungsunterschrift nicht. Grundsätzlich wird persönlich beim Amt unterschrieben.

Was gilt bei Krankheit oder körperlicher Beeinträchtigung?

Wer das Amt deshalb nicht aufsuchen kann, kann dort ein amtliches Sonderverfahren erfragen. Bitte wenden Sie sich dafür direkt an das Amt für Statistik und Wahlen.

Wo finde ich das Wahlprogramm?

Die politischen Vorhaben von Getu Abraham finden Sie auf seiner Website.
